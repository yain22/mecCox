Status: complete main results independently audited; exact public summaries and
private/public PNG and PDF-raster comparisons passed. No results or figures are
created by sourcing these helpers. Running a scenario and exporting its results
are separate, explicit actions. The existing scenario1.R/scenario2.R interactive

Inputs and policy
The fitting adapter and exact RNG/configuration bundle are final_study_helpers.R
and final_reference/. Their six prescribed real-fit replay checks passed; no
additional complete study is required merely to validate the summary/redraw path.
The redraw accepts only all 30,000 final datasets, 1,000 attempts in every cell,
and all 135,000 model rows. All failures and finite extremes remain in the data.
The publication policy is independent_primary targets plus legacy_finite fitting
eligibility: finite estimate and SE for bias/RMSE; finite ordered confidence
limits additionally required for interval coverage. Coverage numerator,
denominator and covered/attempted rate are explicit. Legacy-target, MCSE-shift
and strict-valid summaries are retained separately, never substituted per cell.

Audited reference export (maintainer workflow)
In a new R session, source final_figure_helpers.R, then explicitly call:

  export_audited_final_reference(
    results_path = "/study/analysis/main_results.rds",
    gate_path = "/study/analysis/INDEPENDENT_COMPLETE_AUDIT_PASSED.rds",
    target_binding_path = "/study/analysis/target_binding.rds",
    output_directory = "/new/empty/reference-directory")

This checks the collector/audit/target hashes, exact frozen grid and all
135 primary summaries against the raw results. It writes a portable RDS, raw
attempted model rows, summary/denominator and target CSVs, separate sensitivity
summaries, raw calibration counts and SHA256.csv. It does not fit models or
render figures. Public provenance uses hashes/relative identities, not personal
local source paths. The reference export must be independently reviewed before
being included in a release; an audit flag alone is not a release declaration.

Exact original redraw
Use a separate rendering R library/session with ggplot2 4.0.0, patchwork 1.3.2
and gtable 0.3.6. The verified fitting dependency snapshot remains unchanged
(it records ggplot2 4.0.3). dplyr, labeling, digest and grid are also required.
Do not switch an already loaded ggplot2 namespace; start a fresh R session.
The local reference plotting library can be added through .libPaths() before
loading packages. On Windows, shortPathName() avoids glob interpretation of
square brackets in a library path. No automatic package installation occurs.

  source("/repo/inst/reproduce/final_figure_helpers.R")
  redraw_final_figures(
    "/reference-directory/final_figure_reference.rds",
    "/new/empty/figure-directory")

Or, with the pinned library available through R_LIBS_USER:
  Rscript redraw_final_figures.R --reference=/reference-directory/final_figure_reference.rds --output=/new/empty/figure-directory

The renderer evaluates exactly eight original plotting assignments from the
hash-bound complete revised sources in final_plot_reference/. It creates the
two 12 x 9 inch PNG/PDFs, full plotted data, device/session metadata and artifact
hashes. No changes to colours, fonts, markers, lines, legends, labels, automatic
finite ranges or panel layout are introduced. The source's commented 12 x 14
example is superseded by the actual 12 x 9 published devices. See the plotting
reference README for device/font and cross-platform limits. Inspect the PNGs
and rendered PDF pages before replacing manuscript figures.

Optional complete public-run numeric comparison
If full current scenario1_results and scenario2_results objects already exist,
the following compares all raw model rows and all primary summary cells against
the audited reference. It launches no fits. Default absolute tolerance is zero;
any deliberate tolerance change is saved in the comparison verdict.

  compare_final_driver_results(scenario1_results, scenario2_results,
    "/reference-directory/final_figure_reference.rds",
    "/new/empty/comparison-directory")

Incomplete, duplicated, wrong-grid or wrong-target inputs are rejected. Every
numeric/label/error mismatch is saved; nothing is replaced to force agreement.
Raw target-NA captures and all failure diagnostics must still be present.
This optional check is distinct from the no-refit complete-data summary/redraw
verification performed on the already completed scientific run.

All export destinations must be empty. Existing files are never overwritten.
No current fitting source, frozen stream, target policy or manuscript is edited
by this workflow. The completed main-data path passed independent numeric verification and visual
QA. Private/public primary summaries were compared at absolute tolerance zero;
both PNGs and PDF rasters matched exactly. Internal reference-reading sanity
checks use their separately labelled 1e-13 tolerance. The package/publication
release is managed separately; this workflow does not publish or replace files.
